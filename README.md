# ComputeRift

Manages real-time compute resources and job scheduling for Linux clusters and high-performance computing environments.

ComputeRift is built to be simple and practical, focusing on doing one thing well.

**Why ComputeRift?**

- Manages real-time compute resources and
- job scheduling for Linux clusters
- and high-performance computing environments

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/ComputeRift.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ComputeRift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
